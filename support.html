VaultLedger Support

Help center and frequently asked questions

Getting Started

Quick Start: VaultLedger works entirely offline. No account creation or internet connection required. Just open the app and start tracking your finances!

Key Features

  • Dashboard: View your financial overview including total balance, income, expenses, and detected subscriptions
  • Transactions: Add, edit, and categorize income and expense transactions
  • Import: Import bank statements from CSV and PDF files
  • Budgets: Set and track spending limits by category
  • Net Worth: Track your net worth over time with visual charts
  • Subscriptions: Automatically detect recurring charges from your transaction history
  • Settings: Manage accounts, security, data export, and backups

Frequently Asked Questions

Is my data safe?

Yes! All data is stored locally on your device with optional AES-256 encryption. You can enable biometric lock (Face ID/Touch ID) for additional security. We never collect or transmit your data to any server.

How do I import bank statements?

  1. Go to the Import tab
  2. Choose CSV or PDF format
  3. Select your bank statement file
  4. For CSV: Map the columns to the correct fields
  5. Review the imported transactions and confirm

What CSV format is supported?

VaultLedger supports standard bank CSV exports. The required columns are: Date, Description, and Amount. You can map columns during the import process. Supported date formats include: MM/DD/YYYY, DD/MM/YYYY, and YYYY-MM-DD.

How does subscription detection work?

VaultLedger analyzes your transaction history to identify recurring charges with the same merchant and similar amounts. It looks for patterns like monthly, quarterly, or annual charges and displays them in the Subscriptions section.

How do I backup my data?

  1. Go to More → Settings
  2. Tap Backup Data
  3. Choose where to save the backup file

To restore: Tap Restore Backup and select your backup file.

How do I export my transactions?

Go to More → Settings → Export CSV. This will generate a CSV file that you can share via the iOS share sheet.

Does the app work offline?

Yes! VaultLedger is designed to work completely offline. All features work without an internet connection. The only online features are the support/privacy policy links and the contact support form.

Important: Since all data is stored locally on your device, please make regular backups. If you delete the app, all data will be permanently lost unless you have a backup.

Troubleshooting

  • Import not working: Ensure your CSV file uses UTF-8 encoding and has proper column headers. For PDF, only text-based PDFs are supported (not scanned images).
  • Biometric auth not available: Make sure Face ID/Touch ID is enabled in your device Settings and that VaultLedger has permission to use it.
  • Backup restore fails: Ensure the backup file was created by the same version of VaultLedger and hasn't been modified.
